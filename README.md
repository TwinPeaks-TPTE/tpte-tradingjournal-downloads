# TPTE Tradingjournal – öffentliche Downloads

Dieses öffentliche Repository ist die offizielle Auslieferungsstelle für das TPTE Tradingjournal.

## Aktuelle Version

- Downloadseite: <https://twinpeaks-tpte.github.io/tpte-tradingjournal-downloads/>
- Vollständige Anleitung v0.17.1: <https://twinpeaks-tpte.github.io/tpte-tradingjournal-downloads/anleitung.html>
- Aktuelles Release: <https://github.com/TwinPeaks-TPTE/tpte-tradingjournal-downloads/releases/latest>
- Stabiler Direktdownload: <https://github.com/TwinPeaks-TPTE/tpte-tradingjournal-downloads/releases/latest/download/TPTE-Tradingjournal-Clean-latest.zip>

## Inhalt

Dieses Repository enthält ausschließlich:

- die öffentliche Downloadseite,
- die vollständig eigenständige interaktive Anleitung mit synthetischen Beispieldaten,
- Installations- und Updatehinweise,
- die vollständige öffentliche Versionshistorie aus `CHANGELOG.md`,
- geprüfte Release-ZIPs und SHA-256-Prüfsummen in GitHub Releases.

Der Quellcode, Entwicklungsverlauf und interne Daten verbleiben im privaten Entwicklungsrepository. Persönliche Handels-, Kunden-, Import-, Medien- oder Backupdaten dürfen hier niemals veröffentlicht werden.

## Veröffentlichung

Neue Releases werden ausschließlich über den dokumentierten Release-Prozess des privaten Entwicklungsrepositories bereitgestellt. Das öffentliche ZIP ist ein zuvor geprüftes Build-Artefakt; die Downloadseite liest Versionsnummer, Release Notes und Prüfsumme aus dem jeweils neuesten öffentlichen GitHub Release. Das öffentliche `CHANGELOG.md` wird beim Veröffentlichen automatisch aus der kanonischen Datei des privaten Entwicklungsrepositories synchronisiert.
