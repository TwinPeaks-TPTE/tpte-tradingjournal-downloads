# TPTE Tradingjournal installieren und aktualisieren

## Neuinstallation

1. Lade das aktuelle ZIP über die offizielle Downloadseite herunter.
2. Entpacke das ZIP vollständig.
3. Kopiere `TPTE-Tradingjournal-App` an den gewünschten Ort.
4. Kopiere `TPTE-Tradingjournal-Data-Template` daneben und benenne den Ordner in `TPTE-Tradingjournal-Data` um.
5. Starte die App über `TPTE-Journal.html` oder den Starthelfer für macOS beziehungsweise Windows.
6. Wähle im Setup den Ordner `TPTE-Tradingjournal-Data` aus.

## Update

1. Erstelle vor dem Update ein Backup deines bestehenden Datenordners.
2. Beende das Journal vollständig.
3. Ersetze ausschließlich den bisherigen Ordner `TPTE-Tradingjournal-App` durch die neue Version.
4. Behalte deinen bestehenden Ordner `TPTE-Tradingjournal-Data` unverändert.
5. Starte die neue App und verbinde wieder denselben Datenordner.

> **Wichtig:** Ersetze bei einem Update niemals deinen bestehenden Datenordner durch `TPTE-Tradingjournal-Data-Template`. Das Template ist ausschließlich für Neuinstallationen bestimmt.
